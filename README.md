# Yahara Chocolates & Tea – design preview

Static HTML/CSS/JS design preview (Track A) of a proposed redesign of https://yaharachocolate.com.
**Not the live store.** Every page carries `noindex, nofollow`, the site sends `X-Robots-Tag: noindex`, and checkout/forms are disabled (demo only).

Pages: index, cafe, events, about, chocolate-tastings, pottery, contact, collection, product.
